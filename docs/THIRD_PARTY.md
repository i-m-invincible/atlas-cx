# Third-party assets

The frontend bundles Latin normal variable WOFF2 files from the locked
`@fontsource-variable/source-serif-4` and
`@fontsource-variable/instrument-sans` packages. Fontsource distributes these fonts
under the SIL Open Font License. Copies of both license notices are included in
`frontend/public` and distributed with the built site. The build emits fonts as local assets; it makes
no Google Fonts request. CSS binds them to the two Organic family names required
by DESIGN_SYSTEM.

No photographs, generated artwork, customer logos, testimonials, or model
artifacts are included in this foundation.
